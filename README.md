# Employee Attrition Prediction

## Project Overview
This project focuses on analysing employee attrition and predicting employee turnover using Data Analysis and Machine Learning techniques.

Completed as part of my Data Science Internship at **Naviotech Solution Pvt. Ltd.**

## Project Objectives
- Analyse employee attrition patterns.
- Perform data cleaning and exploratory data analysis.
- Identify important factors related to employee attrition.
- Apply statistical tests.
- Build and compare machine learning classification models.
- Evaluate model performance and generate business insights.

## Dataset Description
- Total Records: 1,500
- Total Columns: 26
- Target Variable: Attrition (Yes/No)
- Employees who stayed: 1,203 (80.2%)
- Employees who left: 297 (19.8%)

## Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- SciPy
- Scikit-learn

## Machine Learning Models
- Baseline Model
- Logistic Regression
- Decision Tree
- Random Forest

## Model Performance

| Metric | Score |
|---|---:|
| Accuracy | 89.0% |
| Precision | 100.0% |
| Recall | 44.1% |
| F1-score | 61.2% |
| ROC-AUC | 79.9% |

## Key Findings
- Overall attrition rate: 19.8%.
- IT department recorded the highest attrition rate.
- Assistant roles showed the highest attrition rate among the analysed job roles.
- Years Since Last Promotion was the leading feature in permutation importance.
